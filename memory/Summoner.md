# 召喚師 Summoner (Summoner)

**用途**:UWU(絕・究極武器破壞作戰)固定同步在 70 級,寫死亡片段的死因分析時用來查這個職業在 70 級同步下實際有哪些技能、每個技能的用途,判斷玩家死亡當下手上有沒有對應的減傷/位移/爆發技能可用。

**來源**:https://ff14.huijiwiki.com/wiki/召唤师 ,現行版本(7.51)資料,2026-07-26 讀取整理。**特別提醒**:召喚師的召喚獸/寶石獸機制在近幾個版本被大幅重做過多次(不再是舊版的迦樓羅/伊弗利特/泰坦分靈+龍神變身系統,而是「寶石獸(紅/黃/綠寶石)輪替 + 龍神附體/巴哈姆特召喚」的資源循環),此表僅依現行版本(7.51)wiki實際顯示的解鎖等級整理,不要用舊版本(如4.x風水火分靈)的記憶去判斷技能用途。

## 70 級當下的重點提醒

- SMN 在 70 級同步下幾乎所有輸出技能都是瞬發或極短詠唱(毀滅/毀壞/毀蕩/迸裂系皆瞬發),沒有以太步/魔紋步這類位移技能;因此死因多半不是「卡詠唱來不及動」,而是純粹站位/走位沒躲開機制。
- 守護之光(2級)是本職唯一自帶的自身減傷手段,抵銷20%最大HP傷害且可疊2次,但發動條件是寶石獸處於「同行狀態」——如果死亡當下寶石獸剛好因為龍神附體/巴哈姆特顯現而被暫時回收,守護之光會無法使用,這種情況下沒開減傷屬於正常限制而非操作失誤。
- 灼熱之光(66級)是團隊傷害增益技能,不提供任何減傷效果,分析死因時不用考慮它有沒有開。
- 龍神附體/龍神召喚(58級/70級,CD60秒)期間輸出循環會被鎖定在固定連段(星極脈衝/星極核爆/死星核爆/真龍波等自動或半自動技能),若死亡發生在這個爆發窗口內,玩家操作彈性比平常更低。
- 醫術(4級)雖然是自我回復手段,但回復量小且佔用GCD,實戰中極少作為保命手段使用,不必因為死亡當下沒有使用醫術就判定為操作失誤。
