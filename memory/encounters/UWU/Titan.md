# 泰坦(P3) — UWU 究極武器破壞作戰

**來源**:
- 灰機wiki https://ff14.huijiwiki.com/wiki/究极神兵绝境战 (現行版本7.51,2026-07-26讀取)
- 究極武器破壞作戰(絕/UWU)機制對照表原始資料:https://gl.ffsusu.com/jsb/shenshen/p3a.html, p3b.html (2026-07-24讀取)

**階段時長**:
- P3 泰坦覺醒前:約1:00。大地粉碎→大地之怒→碎岩/山崩→大地之重(2次)→爆破岩石+花崗石牢/污泥→怒震,持續讓泰坦踩污泥即可觸發覺醒。
- P3 泰坦覺醒後:約1:55(累計到2:55)。大地之重(覺醒,3次)→地裂(覺醒)→怒震→碎岩/山崩→爆破岩石→大地之重(覺醒)→地裂(覺醒)→怒震收尾,2:45內未擊殺則狂暴團滅。

**注意**:本階段部分技能(大地之重、地裂)會在 P4 究極神兵階段沿用,詳見 `UltimaWeapon.md`。另外「大地之怒」這個技能名稱在本階段被用在兩個完全不同的招式上(開場的全體大傷害 vs 尾段的硬狂暴團滅技),查表時務必依死亡時間點所在區間判斷是哪一個,不要只看名稱。

## 一擊必殺(即死)類技能

| 技能名稱 | 機制說明 | 死因判讀 |
|---|---|---|
| 大地粉碎 | 開場時泰坦從天而降,落於場地中心,發動隨與泰坦距離遞減傷害的全屏AOE,離泰坦太近(不到半場距離)即被秒殺;之後每次泰坦轉向、跳起並降落在正點時會再次發動同類攻擊,且每次發動都會讓場地外側的即死區域向內擴散(有範圍預兆),即安全區持續縮小 | 站太靠近泰坦下落點被距離衰減AOE打死,或沒注意到安全區縮小、站到縮小後的場外即死 |
| 碎岩 | 泰坦對當前仇恨目標(通常是坦克)發動無讀條、無預兆的高傷害扇形攻擊 | 坦克減傷沒跟上被直接打死;命中非坦克玩家通常是站位太靠近仇恨目標的扇形範圍內被波及 |
| 山崩 | 泰坦朝當前仇恨目標方向發動無讀條、範圍更大的巨額傷害扇形AOE攻擊(比碎岩範圍更廣) | 站在仇恨目標與泰坦連線的扇形範圍內被波及,常見是坦克沒把泰坦轉向遠離隊伍,或近戰DPS站得太靠近仇恨目標連線 |
| 花崗岩衝擊 | 花崗石牢讀條發動的技能,對被關住的玩家造成秒殺級全屏高傷害AOE,需要在讀條結束前把牢籠打破;覺醒後讀條時間縮短(約3個GCD內要打破) | 團隊輸出/處理牢籠不夠快,救援不及,讀條結束時人還被關在牢裡 |
| 大爆炸(爆破岩石) | 爆破岩石落地後讀條「大爆炸」,結束時產生較大範圍、有明確範圍提示的秒殺級AOE | 讀條結束時還留在範圍內 |
| 塌方(衝擊,爆破岩石落地瞬間) | 爆破岩石落地瞬間,周邊產生小範圍秒殺級衝擊AOE,同時會直接打破所在位置的花崗石牢;若牢籠是被這種非輸出方式(落石衝擊)打破,會產生一次新的追蹤爆炸,爆炸後原地留下污泥區域——玩家踩到污泥是秒殺級DOT,泰坦踩到污泥反而會推進覺醒進度(對玩家是陷阱);若牢籠是被玩家技能傷害打破,則不會有追蹤爆炸與污泥。污泥實際判定範圍比動畫圖示要小 | 站在落石衝擊點附近被秒殺,或誤踩前一次牢籠被爆破後留下的污泥區域 |
| 地裂 | 泰坦以場上除當前仇恨目標外的隨機一名玩家所在位置為中心,朝正面及左右四個斜角共五路發動直線AOE攻擊,附加大幅擊退效果 | 站在其中一條直線AOE路徑上被擊中並擊退到場邊摔死;也可能是被擊退彈到其他危險區域(縮小後場外、污泥等)而死,不完全是直線AOE本身的傷害 |
| 地裂(覺醒後) | 泰坦覺醒後,原本的五路地裂之間會額外追加一次「無預兆/不可見」的六路(六字形)直線地裂攻擊,同樣附加大幅擊退 | 只閃避了看得到的那組五路直線AOE,沒有預留躲避看不到那組(無預兆追加六路)的空間與時間 |
| 大地之怒(狂暴/團滅技) | 若在時間限制內(約2:45)未擊殺泰坦,泰坦進入不可選中狀態,發動狂暴技能「大地之怒」,造成團滅級傷害 | 輸出進度不足觸發硬狂暴導致的團滅,不是單一玩家站位問題 |

## 持續傷害/補量類技能

| 技能名稱 | 機制說明 | 死因判讀 |
|---|---|---|
| 大地之怒(開場) | 開場後不久,泰坦發動全體AOE傷害,傷害數字超過玩家血量上限(數值會被血量上限截斷顯示),需要坦克/治療準備好減傷或護盾 | 沒有開減傷/護盾情況下硬吃,或本身已因其他傷害導致血量偏低時疊加致死,屬補量/減傷判讀而非單純躲避問題 |
| 大地之重 | 隨機點名數名玩家,腳下出現圓形AOE,離開即可,連續出現2次(覺醒後3次) | 若FFLogs顯示是「一擊必殺」通常是站在圈內沒離開;若是疊時間的持續傷害型態,代表走位慢了但還沒完全站穩圈外 |
| 大怒震 | 3秒讀條,以泰坦為中心全屏小傷害並擊退,擊退瞬間全場眩暈2秒(無法用位移技能提前跑開,防擊退技能也無效) | 死因多半是擊退後被彈到危險區域,而非傷害本身 |
| 怒震 | 連續跺地板全屏AOE,6~8次魔法傷害,每次約8000 | 純粹的補量/減傷問題,治療沒跟上連續跳的傷害 |
| 怒震(覺醒後) | 泰坦獲得覺醒狀態後,怒震每次傷害提高 | 覺醒後傷害提高,若治療/減傷沒有相應提升,補量缺口會被放大,比覺醒前更容易死於連續跳的怒震 |

## 其他機制(不直接致死,但影響判讀)

- **攻擊(普通攻擊)**:泰坦對當前仇恨目標的單體無屬性打擊傷害,有機率暴擊,本身不構成秒殺,是坦克日常減傷/格擋處理的對象,不需特別提防。
- **開場不可選中**:泰坦降落(大地粉碎)前處於不可選中狀態,降落完畢後才能被攻擊/嘲諷,影響開場前幾秒的仇恨判定。
- **花崗岩牢獄**:點名三名除當前仇恨目標外的隨機玩家,腳下出現點名標記,隨後被附加狀態並原地產生花崗石牢(禁錮)。此技能本身不致死,但決定了誰會被關、需要團隊在花崗岩衝擊讀條結束前打破牢籠(見上方一擊必殺表),分擔輸出責任不足才是後續致死的根本原因。
- **覺醒狀態**:泰坦透過花崗石牢被爆破岩石(塌方)打破留下的污泥區域,由泰坦自己踩踏累積進度後進入「覺醒」狀態(概念同迦樓羅/伊弗利特的覺醒),覺醒後會強化多個技能:花崗岩衝擊讀條縮短、地裂追加無預兆六路攻擊、大地之重疊加至3輪、怒震傷害提高。判讀死因時需先確認死亡時間點是否已過覺醒切換點,才能套用對應強化後的版本。
- **P3→P4過場**:當泰坦血量被降至1時,當前詠唱結束後泰坦進入不可選中狀態,直接進入下一階段,不是死亡機制,只是階段轉換的判定點。
