# 迦樓羅(P1) — UWU 究極武器破壞作戰

**來源**:
- 灰機wiki https://ff14.huijiwiki.com/wiki/究极神兵绝境战 (現行版本7.51,2026-07-26讀取)
- 究極武器破壞作戰(絕/UWU)機制對照表原始資料:https://gl.ffsusu.com/jsb/shenshen/p1.html (2026-07-24讀取)

**階段時長**:約0:00~2:57(含覺醒後續)。開場螺旋氣流→寒風之歌+大龍捲風→刺羽/柔羽小怪戰+高氣壓圈消除→烈風刃→大氣爆發→迦樓羅分身+邪輪旋風/台風眼→中高壓收尾(完成覺醒)→(若未覺醒/超時)覺醒版邪輪旋風+下行突風全滅。

**注意**:本階段部分技能(飛翎雨、中高壓、台風眼)會在 P4 究極神兵階段沿用,詳見 `UltimaWeapon.md`,該處只列差異,完整機制說明以本檔為準。

**覺醒(Awakened)機制通則**(三蠻神共通):玩家依序擊敗迦樓羅、伊弗利特、泰坦,牠們並不會被直接擊殺——血量降至1時,當前咏唱結束後會進入不可選中狀態,直接進入下一階段;但如果副本時間軸已經到達該蠻神的狂暴時間點,即使血量已降到0,蠻神仍會存活並執行狂暴造成團滅。各蠻神透過不同方式累積[覺醒]狀態,集滿3層後變為[覺醒],提高10%傷害。擊殺處於[覺醒]狀態的蠻神,其死亡位置會留下以太,任意玩家撿取後獲得「突破極限」,持有此狀態時使用三段極限技會重新填滿極限槽。

## 一擊必殺(即死)類技能

| 技能名稱 | 機制說明 | 死因判讀 |
|---|---|---|
| 寒風之歌 | 點名隨機一名治療職發動直線AOE,線上其餘玩家約承受9000傷害;第1個被命中的玩家承受大量傷害(3萬以上),並在其原地留下「大龍捲風」(見下一列)。**傷害數字有分歧**:來源B(舊資料)寫首命中者約10萬(需坦克減傷擋)、其餘連線者約25000,與來源A(灰機wiki)的9000/3萬+有明顯落差,原因未查明(可能是版本調整或舊資料估算失準),寫死因分析時請以FFLogs當場實際傷害數字為準。 | 若受到的傷害接近9000且未標一擊必殺,通常是站在直線上但非首名命中者;若傷害達3萬以上甚至更高,通常是被點名的治療本人且未獲得坦克減傷保護。 |
| 大龍捲風 | 寒風之歌判定時,在首名被點名者原本所在位置留下大龍捲風,玩家進入(或沒有離開)後會受到高額傷害,幾乎即死。 | 站位/走位問題——判定生成後沒有離開原地,或誤走回該位置。 |
| 螺旋氣流 | 迦樓羅朝當前面向發動扇形範圍攻擊(讀條約2.5秒),命中造成大額傷害並附加眩暈。 | 站在正面、沒有利用讀條時間走開。 |
| 下行突風 | 無讀條,朝當前擁有最高仇恨(通常是MT)的玩家方向發動扇形範圍攻擊,造成約15000傷害。 | 因無讀條預警,死因通常是站在迦樓羅面向仇恨目標的扇形範圍內反應不及,或不清楚本體/分身面向的判定方式。 |
| 下行突風(巨型/後期版) | 無讀條,朝當前MT方向發動巨型扇形範圍攻擊,傷害遠高於一般版本且設計上需要分攤;常出現在迦樓羅未於時限內完成覺醒、戰鬥拖到收尾連段時。 | 此版本傷害極高且要求分攤,死因通常是分攤站位沒跟上,或此連段本身就是收尾團滅連段的一部分(見上方階段時長「覺醒版邪輪旋風+下行突風全滅」)。 |
| 台風眼 | 場地邊緣出現環形AOE,任何玩家進入後會受到傷害並被擊退彈回場地中央方向。P4究極神兵階段沿用,完整機制以本檔為準。 | 站位太靠外側、沒注意到AOE已生成;非坦克被擊退時常見死亡,可能是傷害本身加上擊退路徑撞上其他機制所致。 |
| 邪輪旋風 | 讀條後,以迦樓羅為中心發動圓形高傷害範圍攻擊,判定範圍內即死。 | 沒有遠離迦樓羅。 |
| 邪輪旋風+邪氣龍捲(後續兩段版) | 分身/覺醒後的版本:發動邪輪旋風(第1段,以迦樓羅為中心,有預兆)後,緊接著無讀條追加「邪氣龍捲」(第2段,同樣以迦樓羅為中心的環形/甜甜圈狀高傷害範圍,無預兆)。兩段都是即死判定。 | 常見死因是「頂著第1段躲開後,忘記立刻靠近迦樓羅去躲沒有預兆的第2段(邪氣龍捲)」。 |
| 飛翎雨 | 迦樓羅(或分身)升空瞬間,對隨機5名玩家的「當下位置」生成小型圓形延遲AOE,命中後附加15秒「裂傷」。**傷害/持續時間有分歧**:來源A(灰機wiki)僅寫命中後附加15秒裂傷,未給出具體傷害數字;來源B(舊資料)描述為命中時約3萬傷害,並疊加每秒約14000~16000的裂傷DOT、持續18秒,傷害+DOT總和幾乎必死,官方攻略甚至直接寫「等於死亡」。兩者對裂傷秒數與是否有額外瞬間爆傷的描述不完全一致,原因未查明,寫死因分析時請以FFLogs當場實際傷害數字為準。 | 幾乎不可能單純靠治療撐過,只能靠走位提前避開延遲AOE的落點;若FFLogs顯示有一定治療量但仍死亡,通常是裂傷DOT效果太痛而非治療不夠。 |
| 中高壓 | 由分身(來源A稱之為「美翼」「妙翅」)對隨機一名玩家拉線(連線可被截斷),一段時間後對連線玩家造成小範圍AOE傷害「中高壓」。若該玩家身上沒有[低氣壓]層數,中高壓會造成極高傷害(幾乎即死);若身上持有任意層數[低氣壓],則只受到少量傷害。判定發動時另外會給予玩家3秒的追加效果(來源A原文此處文字擷取不完整,無法確認狀態名稱)。 | 死因通常是「身上沒有[低氣壓]層數卻被中高壓命中」,跟血量/治療完全無關,而是有沒有事先透過烈風刃/刺羽等方式取得[低氣壓]層數的問題。 |
| 剛羽(羽槍碰撞) | 剛羽是不可選中的雜兵,在場地上逆時針環繞移動,一定時間後會移動至隨機玩家,與其碰撞後產生大範圍圓形範圍攻擊「羽槍」,造成高額傷害。若當下已觸發超級氣旋,剛羽會原地直接發動羽槍而不需碰撞。 | 死因通常是站位不慎擋到剛羽的移動路徑,或被剛羽鎖定後沒有留意閃避;超級氣旋觸發後剛羽會原地發動羽槍,此時死因多半是對範圍缺乏警覺。 |
| 刺羽(死亡大暴風) | 刺羽被擊殺瞬間,在其所在位置發動「大暴風」,對圓形範圍造成極高傷害(該傷害可能暴擊),並留下持續20秒的[高氣壓]場地——進入此區域的玩家會獲得[高氣壓];若在區域內失去[高氣壓]狀態,需離開後再次進入才能重新獲得,且不會因玩家死亡而消失。 | 死因通常是「擊殺刺羽的瞬間沒有站開」或被牽制在爆炸範圍內;爆炸後留下的20秒[高氣壓]場地也是後續超級氣旋層數的重要來源,不熟悉這塊區域存在的話,可能誤觸而莫名其妙揹上[高氣壓]。 |

## 持續傷害/補量類技能

| 技能名稱 | 機制說明 | 死因判讀 |
|---|---|---|
| 烈風刃 | 對除當前仇恨最高目標以外的隨機一人發動圓形範圍攻擊,造成約8500傷害,同時賦予範圍內所有玩家1層[低氣壓]。附加[低氣壓]的時機依當下狀態而不同:若咏唱結束時玩家已持有[高氣壓],要等到烈風刃傷害實際出現時才會獲得[低氣壓];若玩家不持有[高氣壓],則咏唱結束時立即獲得[低氣壓]。 | 約8500傷害通常不足以在滿血時直接致命,若因此死亡多半是疊加了其他傷害,或死亡當下血量已偏低;由於烈風刃也是[低氣壓]層數的主要來源之一,若之後中高壓/超級氣旋造成非預期死亡,根本原因也可能要追溯到這裡沒有拿到[低氣壓]層。 |
| 寒風之嘯 | 全體傷害,約14000。 | 屬於補量型技能,死亡原因多半是治療覆蓋/減傷沒有安排到這個時間點,或恰好與其他傷害疊加,而非站位問題。 |
| 大氣爆發 | 全體傷害,約17500。另外,同名技能「大氣爆發」在迦樓羅進入不可選中狀態(即戰鬥時限到、蠻神狂暴)的情況下,會被作為狂暴技能使用。 | 一般版本死因是團隊減傷/治療沒跟上此次全體傷害;若整團同時死於本技能,優先檢查是否為戰鬥時限到、迦樓羅狂暴團滅的情況,而非單純補量不足。 |
| 超級氣旋 | 當一名玩家持有[高氣壓]時,該狀態會被消除並觸發一次全屏傷害「超級氣旋」,傷害量依觸發時的[低氣壓]層數而定,詳見下方「其他機制」的層數說明。 | 若團滅或大量死亡發生在此技能上,通常代表[低氣壓]層數已經疊到高層(2~3層)才觸發,而非單次觸發的固定傷害;檢查死亡當下的層數判定比檢查傷害數字本身更有意義。 |
| 刺羽鎖定傷害 | 刺羽會鎖定第一個對其造成仇恨的玩家(通常是率先開怪的坦克或近戰),每8秒對該鎖定目標造成單體氣旋傷害,約15000,並給予其1層[低氣壓]。 | 死因通常是被鎖定的玩家(常是坦克或最先開怪者)減傷/治療沒有安排到位;若非預期人選意外先觸怒刺羽而被鎖定,死亡率會更高。 |
| 柔羽/熱流 | 柔羽會連線一名進攻職能玩家並靠近,一定時間後發動「熱流」,為全員附加30秒睡眠。 | 熱流本身不直接造成傷害,死因通常不是熱流本身,而是玩家在睡眠狀態中恰好被其他一擊必殺機制(如飛翎雨、下行突風)命中卻無法閃避;若FFLogs死亡紀錄的致命一擊技能直接顯示為熱流,較不尋常,建議檢查是否柔羽輸出不足而拖到判定時機。 |

## 其他機制(不直接致死,但影響判讀)

- **普通攻擊**:對當前仇恨目標的單體攻擊,造成無屬性斬擊傷害,有機率暴擊。一般由坦克承受。
- **[低氣壓]/[高氣壓]/超級氣旋層數判定**:無[低氣壓]層數時不會發動超級氣旋;1層時,超級氣旋造成較低全體傷害(約700);2層時造成較高全體傷害(約11000),並為迦樓羅附加1層[覺醒];3層時造成滅團級全屏AOE傷害,同樣為迦樓羅附加1層[覺醒]。若迦樓羅當下處於不可選中狀態,則不會為其附加[覺醒]。[低氣壓]層數主要來自烈風刃、刺羽的單體鎖定傷害;[高氣壓]則來自進入刺羽死亡後留下的20秒場地。
- **召喚羽毛/羽毛小怪刷新規律**:「召喚羽毛」在場地周圍隨機位置生成4個柔羽,首次發動時額外在場地西側生成1個刺羽;後續「召喚羽毛(後)」則在場地4個斜點各生成1個剛羽。三種羽毛小怪各自的行為與死因判讀已列於上方兩張表(柔羽/熱流、刺羽相關兩列、剛羽羽槍碰撞),此處僅記錄刷新規律,方便對照死亡發生在哪個小怪波次。
- **迦樓羅的覺醒累積**:承接上方覺醒通則,迦樓羅主要透過「超級氣旋在2層或3層[低氣壓]時觸發」的方式各自為自己附加1層[覺醒],集滿3層後完成覺醒。團隊通常會刻意控制進入刺羽死亡後[高氣壓]場地的人數與時機,讓超級氣旋盡量落在較輕的1~2層區間觸發,逐步湊滿覺醒層數而不引發滅團級的3層觸發。若整場戰鬥沒能在時限內湊滿覺醒層數,迦樓羅會在收尾階段改用覺醒版邪輪旋風+下行突風(巨型版)的連段強制收尾,通常伴隨團滅。
