# 三神過場秀/最終場(P5) — UWU 究極武器破壞作戰

**來源**:
- 灰機wiki https://ff14.huijiwiki.com/wiki/究极神兵绝境战 (現行版本7.51,2026-07-26讀取)
- 究極武器破壞作戰(絕/UWU)機制對照表原始資料:https://gl.ffsusu.com/jsb/shenshen/p5.html (2026-07-24讀取)

**階段時長**:
P5 三神過場秀(最終):究極傷害產生後→以太波動(全屏擊退+8顆以太炸彈配對引爆,需適當人數撞球)→吸附式炸彈(3人點名,12/32/52秒三種倒數,分攤處理)→隨機順序召喚泰坦/伊弗利特/迦樓羅施放各自覺醒大招→究極神兵召喚「以太值」狂暴讀秒(每秒+2,滿100後依照對王傷害由低到高依序秒殺),需在滿讀秒前擊殺究極神兵,否則團滅。以太化狂暴讀秒約在究極大招後2分鐘左右到來。

(來源A的吸附式炸彈倒數寫作「12/32/52秒」,來源B的舊資料寫作「52/32/12秒三種倒數」——這是同一組三個數字的順序寫法不同,不是真的衝突,本檔採來源A的12/32/52秒表示法:同時有3名玩家分別被附加這三種不同長度的倒數。)

**注意**:
- 本階段開場的「究極」讀條,與P4「亂擊之究極幻想」的收尾是同一次讀條,是P4/P5的交界點。此讀條**之前**的機制(P4檢查點、追擊/爆擊/亂擊三個究極幻想子階段)見`UltimaWeapon.md`。
- 本階段的「以太炸彈」連線長度,取決於P4「爆擊之究極幻想」期間對應那顆以太炸彈有沒有被玩家撞掉,兩者是連動機制,詳見`UltimaWeapon.md`。
- 本階段召喚的迦樓羅/伊弗利特/泰坦覺醒大招,完整機制沿用P1~P3,本檔僅簡述+cross-reference,完整說明以`Garuda.md`/`Ifrit.md`/`Titan.md`為準。

## 蠻神召喚:沿用自 P1~P3 的技能

究極神兵會依序召喚迦樓羅、伊弗利特、泰坦,各自施放一次覺醒版大招。召喚順序是以下三種之一(每場戰鬥隨機擇一,並非六種排列都可能出現):

1. 迦樓羅 → 伊弗利特 → 泰坦
2. 伊弗利特 → 迦樓羅 → 泰坦
3. 泰坦 → 伊弗利特 → 迦樓羅

召喚下一隻王之前,究極神兵身前會先出現對應的顏色特效提示。三王都會出現在場地中心施放技能(伊弗利特額外在兩個正點召喚分身)。以下僅列簡述,完整機制、精確傷害數字與死因判讀請查各自檔案——**不要在這裡重新解釋一次,一律以來源檔案為準**:

| 迦樓羅 | 場地中心 | 覺醒版邪輪旋風(兩段判定,皆即死)、大氣爆發、飛翎雨(命中+DOT「等於死亡」級) | `Garuda.md` |
| 伊弗利特 | 場地中心(本體)+兩個正點(分身) | 本體:地火噴發、地獄之火炎;分身:深紅旋風(即死級俯衝) | `Ifrit.md` |

## 持續傷害/補量類技能

| 技能名稱 | 機制說明 | 死因判讀 |
|---|---|---|
| 以太波動 | 「究極」讀條結束後,究極神兵讀條「以太波動」,對全場造成小範圍擊退(可用防擊退技能完全抵擋),同時在場地四個斜點各自召喚一組以太炸彈(共四組、八顆),為下一個機制鋪陳。 | 本身通常不直接致死;死因多半是被擊退到危險區域(場邊、以太炸彈連線路徑等),而非擊退傷害本身。若隊員此時已死於前面的「究極」,不會再受本技能影響。 |
| 以太炸彈(P5版/融合爆炸) | 以太波動同時在四個斜點召喚兩兩一組的以太炸彈,每組以連線相連,連線長度會隨時間逐漸縮短(兩端逐漸靠近)。**連線初始長度取決於P4「爆擊之究極幻想」期間對應那顆以太炸彈被玩家撞掉的情況**(詳見`UltimaWeapon.md`)。玩家主動撞擊其中一顆,會造成高額但可分攤的傷害,並讓連線另一端的那顆立即消失,視為這組已解決;若時限內兩顆都沒被撞掉、連線靠攏完成,則觸發「融合爆炸」,對全場造成團滅級傷害。**若P4對應那顆以太炸彈在爆擊之究極幻想期間完全沒人撞到、自然過期爆炸,則這一組在P5的連線長度直接視為0,一開場就立刻融合爆炸**,幾乎沒有反應時間。 | 死亡若來自撞擊當下的分攤傷害,代表分攤人數不足或沒站進範圍;死亡若來自「融合爆炸」的團滅級傷害,根本原因通常不在P5當下,而要回頭檢查P4爆擊之究極幻想期間是否有以太炸彈沒被全部撞掉——這是P5開場團滅最常見的成因。 |
| 吸附式炸彈(P5版,12/32/52秒) | 究極神兵對場上距離較遠的玩家造成一次魔法傷害,並在任意3名玩家身上各附加一份「吸附式炸彈」狀態,三人的倒數秒數分別是12秒、32秒、52秒(每人一種、彼此不同)。倒數歸零時爆炸,對範圍內造成高額魔法傷害,可分攤,也可由被點名者自行開減傷單獨承受。 | 死因與P4版本相同:分攤沒到位,或被點名玩家沒開減傷硬吃。三種倒數長度不同,常見疏漏是處理完最短的12秒那組後就鬆懈,忘記32秒/52秒的還在跑。 |

## 狂暴機制:黑蛇究極(團滅計時器)

三王依序施放完覺醒大招後,究極神兵移動到12點,在場地中央召喚出「以太牢籠」,同時究極神兵的「以太」值從0開始,以**每秒+2**的速度持續增加(這段期間沒有讀條、不會中斷,唯一的解法是在以太值到達100之前擊殺究極神兵)。以太值到100大約需要50秒;把P5開場的以太波動/以太炸彈/吸附式炸彈/蠻神召喚等前段機制耗時算進去,整個P5階段(從究極讀條到狂暴讀秒滿)大約落在究極大招後2分鐘左右,與上面的階段時長一致。

以太值到達100後,究極神兵依照**全場玩家對究極神兵造成的總傷害排名,由低到高**依序處決存活玩家:

1. 排名最低(對王輸出最少)的存活玩家先被擊暈,吸入場地中央的以太牢籠,進入「空中拘束」狀態,並受到一次名為「堡壘圍攻」、傷害999999點的攻擊——等同即死。
2. 該玩家死亡後不可再被選中(等同移出戰鬥),究極神兵接著抓下一名排名較低的存活玩家,重複同樣流程。
3. 這個死亡順序**只計算「黑蛇究極開始時仍存活」的玩家**——如果有人已經在以太波動、以太炸彈融合爆炸、吸附式炸彈,或蠻神覺醒大招等P5前段機制中死亡,不會出現在這份處決名單裡,因為他們早就死了。
4. 當存活玩家中排名最高的最後一人也被抓入牢籠、進入空中拘束狀態後,究極神兵發動「黑蛇究極」,對全場所有玩家造成999999點傷害,經過一段演出動畫後強制團滅。

**死因判讀**:FFLogs死亡紀錄裡若致命一擊是「堡壘圍攻」或「黑蛇究極」,幾乎可以肯定戰鬥已經進入無法迴避的最終狂暴——這是全隊沒能在以太值滿100前擊殺究極神兵的DPS check失敗,**不是**死亡當下的個人操作或站位問題。想確認「為什麼是這個人先死」,要回頭比對全隊對究極神兵造成的總傷害排名(通常反映輸出手法、職業配置、或前段機制處理拖慢輸出節奏等問題),而不是看死亡當下有沒有閃避技能。若整團幾乎同時死於「黑蛇究極」本身(而非依序的「堡壘圍攻」),代表處決順序已經跑完整輪,全隊本來就已經在滅團倒數之內。

**附註(來源A trivia)**:「堡壘圍攻」這個技能名稱借用自FF11《忒彌諾斯中央塔》4層單元II的神兵族惡名精英「至高究極神兵(Arch-Ultima)」的同名技能。原作中的堡壘圍攻是血量50%後、每再降10%就會使用一次的無法打斷長詠唱單體即死技;UWU把它改成依對王傷害排名逐一處決全場玩家的版本。

**尚待確認的項目(合併來源A/B時信心不足之處)**:
- **「大地之怒」已對照`Titan.md`確認,跟「大怒震」是兩個完全不同的技能**——`Titan.md`記錄了泰坦本體階段有兩個各自獨立的「大地之怒」(開場的全體AOE傷害、尾段的硬狂暴團滅技),跟另一個單獨的「大怒震」(全屏擊退+2秒眩暈)三者都是不同招式,不是同一機制的不同譯名。本檔P5蠻神召喚裡泰坦使用的「大地之怒」,依上下文(與覺醒版大地之重並列的一般攻擊,而非硬狂暴收尾的措辭)判斷,較可能是重用開場版的全體AOE傷害,而非尾段狂暴團滅版——但灰機wiki原文沒有明確區分是哪一版,查死因分析時請以FFLogs當場實際傷害數字判斷(全體AOE傷害量遠低於999999的團滅級數字,即可排除是狂暴版)。
- 「大氣爆發」在P1階段只出現在舊`UWU_MECHANICS.md`的階段流程簡述裡,沒有被列進任何一張死因判讀表格,本檔沿用這個現況只在「蠻神召喚」摘要裡簡單帶過;若`Garuda.md`日後補上這個技能的完整機制,本檔的簡述應同步更新。
- 「黑蛇究極」處決順序所依據的「對究極神兵造成的傷害」,來源A原文是「本體階段」,解讀為究極神兵本體可被攻擊的期間(P4後段~P5),但沒有明確寫出是否從P4究極神兵初登場就開始累計、或是否併入更早P1~P3對三王造成的傷害(邏輯上應該不併入,因為那些是不同的目標),本檔按照較合理的解讀撰寫,但無法100%確認官方判定範圍。
- 來源B提到的「以太陣」與來源A描述的「以太值以每秒2點增加」,推測是同一個底層數值/計量的不同稱呼(一個是機制名、一個是數值描述),本檔合併處理為「以太值」,未特別區分。
