# 伊弗利特(P2) — UWU 究極武器破壞作戰

**來源**:
- 灰機wiki https://ff14.huijiwiki.com/wiki/究极神兵绝境战 (現行版本7.51,2026-07-26讀取)
- 究極武器破壞作戰(絕/UWU)機制對照表原始資料:https://gl.ffsusu.com/jsb/shenshen/p2a.html, p2b.html (2026-07-24讀取)

**階段時長**:
- P2 伊弗利特覺醒前:約0:00~1:10。光輝炎柱→地獄之火炎→火神爆裂→烈焰焚燒→火獄之楔(4個)+地火噴發配合擊殺+灼熱咆哮/火獄之鎖,擊殺4個楔完成覺醒。
- P2 伊弗利特覺醒後:約1:43(累計到2:53)。烈焰碎擊+詛咒之炎(注意分攤人數)→灼熱咆哮(覺醒,30秒5跳)→深紅旋風(覺醒,含十字火焰)→地火噴發→烈焰焚燒→地獄之火炎收尾,2:45內未擊殺則狂暴團滅。

**注意**:本階段部分技能(地火噴發、光輝炎柱、火神爆裂)會在 P4 究極神兵階段沿用,詳見 `UltimaWeapon.md`,該處只列差異,完整機制說明以本檔為準。

## 一擊必殺(即死)類技能

| 技能名稱 | 機制說明 | 死因判讀 |
|---|---|---|
| 深紅旋風(覺醒前) | 伊弗利特本體與三個分身相鄰出現在正點或斜點,由最外側位置開始依序發動直線俯衝,命中造成大額傷害。**傷害數字有分歧**:來源A(灰機wiki)標示約24000,來源B(舊資料)標示約9萬、擊中非坦克即死,兩者差異未查明原因(可能是版本調降或舊資料估算失準)。寫死因分析時請以FFLogs當場實際傷害數字為準,不要死板套用任一來源的估計值。 | 沒有站到俯衝路徑外的安全點;本體+3分身共4隻依序從最外側往內俯衝,漏算其中一隻的路徑也會導致誤判安全位置。 |
| 深紅旋風(覺醒後) | 覺醒後,本體與三分身改在與「召喚火獄之楔」刷新時類似的位置(正點/斜點)出現,依照火獄之楔被破壞的順序依序發動深紅旋風;本體俯衝2秒後,會再追加一次與原方向正交的俯衝(本體站在正點時追加為X字型,站在斜點時追加為十字型)。同樣即死,傷害數字沿用上方的分歧註記。 | 只閃過第一次俯衝、忘記還有2秒後的第二次正交方向俯衝(X字/十字火焰)。 |

## 持續傷害/補量類技能

| 技能名稱 | 機制說明 | 死因判讀 |
|---|---|---|
| 地獄之火炎 | 伊弗利特讀條後對全體造成傷害,約16500;覺醒後提高至約17500。此技能另有兩種特殊觸發:①若「召喚火獄之楔」在時限內未被全部破壞,會改為強制團滅版;②戰鬥時限(2:45)到仍未擊殺伊弗利特,牠會進入無法選中狀態並以此技能作為硬狂暴收尾。 | 一般讀條版本死因是團隊減傷/治療沒跟上;若整團同時死於本技能,優先檢查是否為「楔沒破壞完」或「戰鬥時限到」的狂暴團滅,而非單純補量不足。 |
| 火神爆裂 | 無讀條,以伊弗利特自身為中心的大範圍AOE,造成約2000傷害並擊退受到傷害的玩家(可用防擊退技能/群體無敵抵擋);若技能未造成實際傷害則不會擊退。P4沿用。 | 死亡代表沒開盾也沒防擊退,被擊退到危險區域(場邊、火獄之楔爆炸範圍、深紅旋風俯衝路徑等)或直接吃到不小的傷害。 |
| 烈焰焚燒 | 對伊弗利特當前仇恨目標(通常是MT)無讀條連續發動3次扇形範圍攻擊,每次約20000火屬性傷害,並各附加5秒「火屬性耐性大幅降低」,間隔3~4秒;此傷害不吃物理/魔法減傷,但吃通用減傷。 | MT沒有排無敵或減傷不夠,第2次開始因疊加的耐性降低debuff而傷害暴增。 |
| 灼熱咆哮 | 對隨機一名治療職造成約1300火屬性傷害並附加18秒「灼熱」狀態(每3秒跳一次約700傷害,不會因死亡而清除);每6秒(倒數13/7/1秒)以該玩家為中心半徑15公尺內對其他玩家造成高額熱風傷害並大幅擊退。覺醒後持續時間延長為30秒(多跳2次)。 | 死因通常是「其他人」站得太近被熱風波及擊退,而非被點名的治療本人;覺醒後從18秒延長到30秒,沒注意到多跳的2次容易誤判安全時間已過。 |
| 火獄之鎖 | 連線伊弗利特當前仇恨排名第2的玩家與隨機一名進攻職能玩家,雙方附加21秒「火獄之鎖」,依雙方距離決定層數:距離越遠層數越高,連線雙方造成的傷害越低、承受的持續傷害越高。任一方倒下會隨機重新連線另一人並重新計時。 | 死因常是誤以為要拉開距離(跟一般"拉開"的鏈子技能相反!),反而越站越遠導致持續傷害爆增。 |
| 地火噴發 | 對當前距離伊弗利特最遠、且身上沒有相關狀態的2名目標,各施放4連圓形範圍AOE;若被點名者中途死亡,改點名另一人繼續發動。覺醒前階段需引導AOE圈覆蓋到火獄之楔上以配合破壞。P4究極神兵階段沿用,詳見`UltimaWeapon.md`。 | 死亡多半是輪到自己被點名時所在位置不對(沒把AOE蓋到楔上或蓋錯地方),或治療沒跟上4連疊加傷害。 |
| 烈焰碎擊/詛咒之炎 | 隨機點名任一進攻職能玩家造成可分攤的傷害(烈焰碎擊)。覺醒後,依照實際分攤人數附加不同秒數的持續傷害狀態「詛咒之炎」,人數越少持續越久、總傷害越高;此狀態不會因玩家死亡而消失。**分攤人數—持續秒數對照表,兩來源不一致**:來源A(灰機wiki)寫1人96秒、2人48秒、3人24秒、4人12秒、5人6秒、6人以上3秒(倍增關係);來源B(舊資料)寫≥6人只持續2秒(不痛)、5人持續4秒(小痛)、低於5人持續30秒(大量死亡)。兩者邏輯一致(人越少越痛)但精確數字有出入。 | 若看到此DOT死亡,幾乎可以肯定是「分攤人數不足」,不是技能本身多致命,而是團隊站位/集合不夠及時。精確秒數/跳傷數字請以FFLogs當場實際數據為準,不要死板套用來源A或來源B任一組數字。 |
| 光輝炎柱 | 全場生成多個圓形範圍AOE,固定4個正點中必有2個位置不生成AOE圈(安全點)。P4究極神兵階段沿用,詳見`UltimaWeapon.md`。 | 沒找到安全點,或誤判哪2個正點才是沒有AOE的位置。 |
| 裂傷(存疑,待查) | 出現於FFLogs死亡紀錄中的一個持續傷害debuff名稱。來源A(灰機wiki)的技能列表中沒有直接對應到叫這個名字的機制,可能是某個技能附帶DOT在遊戲內顯示的debuff名(而非技能施放名),也可能是舊資料整理疏漏。暫時保留,不強行對應到上面任一技能。 | 補量沒跟上的磨死型態;查到此debuff時建議直接看FFLogs當下的傷害/治療數字判斷死因,不要嘗試比對特定技能機制。 |

## 其他機制(不直接致死,但影響判讀)

- **普通攻擊**:對當前仇恨目標的單體火屬性斬擊攻擊,享受火屬性耐性大降debuff帶來的易傷效果,有機率暴擊。一般由坦克承受;若MT身上疊了烈焰焚燒的耐性降低debuff,普通攻擊也會跟著變痛,可能疊加造成非預期死亡。
- **召喚火獄之楔**(覺醒前的核心解謎機制):場上固定出現4根火獄之楔,一定在12/3/9/6點中2個位置、2/4/8/10點中2個位置各出現1根,整體呈等腰梯形站位。楔被破壞時會造成全場「火獄之炎」傷害(約5000)並給全員1層「受傷加重」(持續1秒)——這個爆炸傷害會打到伊弗利特本體,但不會給牠疊加受傷加重;若時限內未破壞完全部4根楔,伊弗利特會改為施放上方「地獄之火炎」的強制團滅版本。楔被地火噴發的AOE命中會疊加「傷害提高」與「受傷減輕」各1層並變大(最多疊2次,之後地火噴發命中不再改變其外觀),此時破壞已疊到最大的楔會讓伊弗利特獲得「以太供應」狀態。**建議死因分析時優先確認死亡是否落在「楔未破壞完→強制團滅」這個時間點,而非單純的補量問題。**
- **覺醒轉換**:伊弗利特血量降至1時,當前咏唱結束後進入不可選中狀態並轉入下一階段,同時驅散全員的「灼熱」debuff;但由於連線延遲、重生狀態等原因,灼熱的清除可能會延遲顯示。分析發生在覺醒轉換前後的死亡個案時,要注意這個延遲可能讓debuff看起來比實際持續得更久。
