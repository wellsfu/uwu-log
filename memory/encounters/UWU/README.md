# UWU(絕・究極武器破壞作戰 / The Weapon's Refrain (Ultimate))

這是**純技能事實索引**,只回答「這隻王的每個技能客觀上做了什麼」。查「這為什麼會死、該怎麼應對」請到 repo 根目錄的 `../../../UWU_MECHANICS.md`(源自破解攻略,死因判讀的主要查表對象)。查玩家職業手上有什麼技能,見 `../../class-abilities/`(見下方同步等級)。

## 來源

- 灰機wiki https://ff14.huijiwiki.com/wiki/究极神兵绝境战(現行版本7.51,2026-07-26讀取)——本資料夾機制文字說明的主要來源。

兩份來源合併時,少數技能的傷害數字/持續秒數兩邊寫得不一樣(例如深紅旋風的傷害量、詛咒之炎依分攤人數對應的DOT秒數、飛翎雨的機制細節),各自的 `<Boss>.md` 檔案裡都有明確標註這些差異,**不要死板套用任一來源的估計值,以FFLogs當場實際傷害/治療數字為準**。

## 同步等級

UWU 固定同步在 **70 級**(角色實際等級不影響機關判定)。查職業手上有哪些技能時,對應 `../../class-abilities/70/<職業識別碼>.md`。

## 重要提醒:技能名稱會跨階段重複出現!

P4(究極神兵)的「追擊之究極幻想」「爆擊之究極幻想」「亂擊之究極幻想」三個組合技子階段,以及 P5(三神過場秀),都會直接重複使用 P1~P3(迦樓羅/伊弗利特/泰坦)的技能。**看到 death log 裡某個技能名稱,不能只看 FFLogs 標的 phase(P1/P2/P3/P5)就假設一定是那隻王本體施放的**——同一個 pull 若時長夠長,一開始的死亡可能還在迦樓羅階段,FFLogs 最後標的「到達階段」只代表這場 wipe 時所在的階段,不代表整場都在那個階段。判斷實際階段要看:

1. 死亡時間點在 pull 內的相對秒數(對照下方各階段大約時長)
2. 技能名稱本身就是最準的線索——但要注意,某些技能名稱在同一隻王身上也會重複代表不同招式(例如泰坦的「大地之怒」同時是開場的全體傷害招和尾段的硬狂暴團滅技,兩者是完全不同的招式,詳見 `Titan.md` 開頭的警告)

各 Boss/Phase 檔案裡,凡是「沿用自其他階段」的技能,只會簡述+標註參照哪一份檔案有完整說明,不會整段複製,查表時記得跟過去看完整機制。

## 各階段大約時長(僅供抓時間區間參考,實際會因處理速度略有增減)

- P1 迦樓羅:約 0:00 ~ 2:57(含覺醒後續)
- P2 伊弗利特覺醒前:約 0:00~1:10(接續前階段時間會重算)
- P2 伊弗利特覺醒後:約 1:10~2:53
- P3 泰坦覺醒前:約 0:00~1:00
- P3 泰坦覺醒後:約 1:00~2:55
- P4 拉哈布雷亞(檢查點):很短,約 1 分鐘內,主要是有沒有正確覺醒前三王的判定
- P4 追擊之究極幻想:約 0:00~1:35
- P4 爆擊之究極幻想:約 1:35~3:05
- P4 亂擊之究極幻想:約 3:05~4:00(含究極大招)
- P5 三神過場秀(最終場):究極大招後約 2 分鐘左右進入以太值狂暴讀秒
