# 舞者 Dancer (Dancer)

**用途**:UWU(絕・究極武器破壞作戰)固定同步在 70 級,寫死亡片段的死因分析時用來查這個職業在 70 級同步下實際有哪些技能、每個技能的用途,判斷玩家死亡當下手上有沒有對應的減傷/位移/爆發技能可用。

**來源**:https://ff14.huijiwiki.com/wiki/舞者 ,現行版本(7.51)資料,2026-07-26 讀取整理(含逐一點開技能頁核對效果)。技能解鎖等級會隨版本改動(relevel)而變化,以此表現行版本等級為準,不要用舊版本記憶判斷。舞者沒有前置基礎職業,轉職後等級從60開始,所有技能都歸類在「職業技能」底下,沒有另外的「特職技能」分類。**舞者的技能組本來就是從60級才開始出現,這是正常設計(轉職即60級),不是資料缺漏。**

**重要校正**:灰機wiki的技能頁面預設顯示的是「滿級(含所有特性強化)」數值,部分技能在高等級(76級/78級/88級/92級/98級等)會有額外特性提升效果量、充能次數或縮短CD。70級同步下這些高等級特性都不生效,本表已按70級當下的實際數值標註(例如「防守之桑巴」滿級是15%減傷,70級同步下只有10%;「前衝步」滿級3次充能,70級同步下只有2次)。

## 70 級當下的重點提醒

- 56級才拿到「防守之桑巴」這個團隊減傷CD(70級同步下為10%減傷、15秒、CD 120秒);56級前舞者完全沒有主動的團隊減傷手段。
- 52級「治療之華爾茲」是舞者唯一的主動治療手段(回HP,範圍5米,CD 60秒);死因分析時若懷疑補量不夠,可以查一下死亡當下這個技能是否在CD中、或死亡的人是否在範圍/舞伴內。
- 50級「前衝步」是舞者唯一的主動位移技能,但止步狀態下無法發動——如果死亡當下角色正處於讀條/僵直,這個技能是用不出來的。70級同步下只有2次充能(不是滿級的3次)。
- 15級「標準舞步」與70級「技巧舞步」的跳舞模式(各持續15秒)期間,玩家只能使用舞步相關技能、前衝步、治療之華爾茲、防守之桑巴、職能技能、衝刺與極限技——也就是說跳舞模式中「看起來卡住不能一般輸出」是正常機制,不是操作失誤;但重點是前衝步/治療之華爾茲/防守之桑巴這三個防禦/位移/治療技能在跳舞模式中仍然可以正常使用,不會被鎖住。
- 32級起有「親疏自行」可短暫免疫擊退/擊寄,是應對UWU裡各種擊退機制(如台風眼、大怒震)的重要手段,但只有一份、有CD,不可能每次擊退都覆蓋。
- 32級前(親疏自行解鎖前)以及沒有CD可用時,舞者跟機工士一樣沒有主動的位移/免疫擊退手段可用。
