# 占星術士 Astrologian (Astrologian)

**用途**:UWU(絕・究極武器破壞作戰)固定同步在 70 級,寫死亡片段的死因分析時用來查這個職業在 70 級同步下實際有哪些技能、每個技能的用途,判斷玩家死亡當下手上有沒有對應的減傷/治療/爆發技能可用。

**來源**:https://ff14.huijiwiki.com/wiki/占星术士 ,現行版本(7.51)資料,2026-07-26 讀取整理。技能解鎖等級會隨版本改動(relevel)而變化,以此表現行版本等級為準,不要用舊版本記憶判斷。多數技能名稱另外交叉查證了對應的 https://ff14.huijiwiki.com/wiki/Action:<id> 技能詳情頁以確認實際效果;少數輸出用咒語(標註「推論」)因效果對死因分析影響不大,僅依命名規律推論為傷害技能,未逐一開頁確認。

## 職能技能(同角色共用,只列 70 級或以下)

**未能取得**:huijiwiki 占星術士頁面的 PvE技能 分頁裡「職能技能」分頁按鈕點擊後內容不會切換(仍顯示職業技能表),與其他三個治療職相同,判斷是該頁面模板本身的顯示問題。已知同為治療職共用的康復(Esuna,10級,淨化目標身上部分弱化狀態)也適用於占星術士(在學者頁面查證時確認其「適用職業」欄位包含占星術士),死因分析時可視為占星術士也持有此技能。其餘職能技能(如救援/位移類、安息/控場類等)未能取得,需要時另外查證。

## 70 級當下的重點提醒

- 占星術士是輸出增益/團隊爆發向的治療職:占卜(全隊傷害+6%,CD120秒)與奧秘卡系統是團隊輸出的重要資源,死因分析時若剛好死在占卜/奧秘卡剛用掉的空窗期意義不大,重點還是看治療與減傷技能。
- 全體減傷只有命運之輪(自身+周圍隊員10%減傷,10秒,CD60秒),但發動後只要移動或出招就會提前消失,若佔星在死亡前必須走位閃機制,這個減傷可能沒撐滿。
- 地星是「延遲爆發」治療:放置後需要等待或手動引爆(星體爆轟)才會真正治療到人,如果死亡發生在地星剛放下、還沒引爆的空窗期,代表這個治療還沒生效。
- 星位合圖需要「配對」目標且需要之後有單體治療施放才會連帶治療到配對對象,不是主動的瞬間治療手段。
- 先天稟賦(單體瞬發,越低血量恢復越多)與天星衝日(範圍瞬發治療)是70級當下比較快的救人手段,CD分別是40秒與60秒,死亡當下若這些都在CD上代表補救手段已經打光。
