# 機工士 Machinist (Machinist)

**用途**:UWU(絕・究極武器破壞作戰)固定同步在 70 級,寫死亡片段的死因分析時用來查這個職業在 70 級同步下實際有哪些技能、每個技能的用途,判斷玩家死亡當下手上有沒有對應的減傷/位移/爆發技能可用。

**來源**:https://ff14.huijiwiki.com/wiki/机工士 ,現行版本(7.51)資料,2026-07-26 讀取整理(含逐一點開技能頁核對效果)。技能解鎖等級會隨版本改動(relevel)而變化,以此表現行版本等級為準,不要用舊版本記憶判斷。機工士沒有前置基礎職業,轉職後等級從30開始,所有技能都歸類在「職業技能」底下,沒有另外的「特職技能」分類。

**重要校正**:灰機wiki的技能頁面預設顯示的是「滿級(含所有特性強化)」數值,部分技能在高等級(88級/98級/100級)會有額外特性提升效果量或縮短CD。70級同步下這些高等級特性都不生效,本表已按70級當下的實際數值標註(例如「策動」滿級是15%減傷,但70級同步下只有10%)。

## 70 級當下的重點提醒

- 56級才拿到「策動」這個團隊減傷CD(70級同步下為10%減傷、15秒、CD 120秒);56級前機工士完全沒有主動的團隊減傷手段。
- 機工士沒有任何主動位移/後跳技能(不像吟遊詩人有後躍射擊),閃避地面AOE只能靠正常跑動。
- 32級起有「親疏自行」可短暫免疫擊退/擊寄,是應對UWU裡各種擊退機制(如台風眼、大怒震)的重要手段,但只有一份、有CD,不可能每次擊退都覆蓋。
- 62級「武裝解除」是對boss的10%傷害降低debuff,持續僅10秒、CD 120秒,分析boss高傷害技能時可以查當下這個debuff是否有覆蓋到。
- 45級「野火」是機工士的爆發核心,結算前若機工士死亡或被打斷輸出,會大幅減少野火的最終爆炸傷害,但這是輸出問題,與死因分析(玩家為什麼死)關聯不大,除非死亡剛好發生在野火/起爆的操作視窗附近導致連鎖影響團隊輸出/覺醒判定。
- 內丹(8級)只是小量自我回血,不能當減傷手段看待;死因分析時不要把它當作能扛住大傷害的依據。
