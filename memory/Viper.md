# 蝰蛇劍士 Viper (Viper)

**用途**:UWU(絕・究極武器破壞作戰)固定同步在 70 級。此檔案存在的原因是「解釋為什麼不用建這個職業的 70 級技能表」。

## 結論:不會出現在 UWU 的死亡紀錄裡

蝰蛇劍士是《黃金的遺產》(7.0 版本)追加的近戰 DPS,職業任務要求主角色等級達到 **100 級**才能解鎖,解鎖後角色本身也是從 **100 級**開始起算,沒有「70 級當下的蝰蛇劍士」這種狀態存在——不像賢者/鐮鐮客(70 級開荒),也不像絕槍戰士/舞者(60 級開荒後可以同步降到 70 級)。

因此玩家不可能帶著蝰蛇劍士進入同步 70 級的 UWU,FFLogs 死亡紀錄裡也不會出現這個職業,不需要另外查技能表。
