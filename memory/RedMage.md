# 赤魔法師 Red Mage (RedMage)

**用途**:UWU(絕・究極武器破壞作戰)固定同步在 70 級,寫死亡片段的死因分析時用來查這個職業在 70 級同步下實際有哪些技能、每個技能的用途,判斷玩家死亡當下手上有沒有對應的減傷/位移/爆發技能可用。

**來源**:https://ff14.huijiwiki.com/wiki/赤魔法师 ,現行版本(7.51)資料,2026-07-26 讀取整理。技能解鎖等級會隨版本改動(relevel)而變化,以此表現行版本等級為準,不要用舊版本記憶判斷。**特別提醒**:赤魔法師是特殊職業,不從基礎職業轉職而來,角色需滿 50 級才能直接解鎖此職業,解鎖當下會一次拿到所有「50級以下」標示等級的技能;因此下表雖然列出1級、2級等等級標籤,實際上是解鎖赤魔法師(50級)時就一次到位,不是逐級練出來的。

## 70 級當下的重點提醒

- RDM 是特殊職業,50級解鎖時所有≤50級的技能一次到位,不存在「還沒練到某個技能」的情況,70級同步下上表所有技能都應該已具備。
- RDM 是本次三個職業中唯一有「近戰位移」工具的:短兵相接(6級,衝向目標)、移轉(40級,後跳離開目標15米)、交劍(40級,衝向目標,與移轉共用CD)。三者都是有CD(35秒)、可疊2次的技能,而且**定身狀態下都無法發動**——死亡分析時若當下角色被定身,或這些技能剛用完還在CD中,就代表位移工具當下用不了。
- 移轉(40級)是唯一能「主動拉開距離」的技能(後跳15米),若死因是被近戰距離的AOE/直線機制打到,可以查當下移轉是否還在CD。
- 鼓勵(58級)只是傷害增益技能,不提供任何減傷效果,不影響死亡分析判斷。
- 赤治療(54級)回復量小(350點)且會佔用GCD,只能算是輔助手段,不是主要保命工具。
- **RDM 本職技能中沒有任何自身減傷/護盾類技能**(不像黑魔法師有魔罩、召喚師有守護之光),死亡當下若沒有開啟任何減傷,是因為本職根本沒有這類工具,只能依靠位移閃避機制,或角色共用的職能技能(沉穩詠唱只防中斷/擊退,不減傷)。
