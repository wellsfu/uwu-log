# 武士 Samurai (Samurai)

**用途**:UWU(絕・究極武器破壞作戰)固定同步在 70 級,寫死亡片段的死因分析時用來查這個職業在 70 級同步下實際有哪些技能、每個技能的用途,判斷玩家死亡當下手上有沒有對應的減傷/位移/爆發技能可用。

**來源**:https://ff14.huijiwiki.com/wiki/武士 ,現行版本(7.51)資料,2026-07-26 讀取整理。技能解鎖等級會隨版本改動(relevel)而變化,以此表現行版本等級為準,不要用舊版本記憶判斷。武士是無基礎職業的特職(轉職後等級直接從50起算),故技能表未再區分「職業技能/特職技能」,以下合併列出。

## 70 級當下的重點提醒

- 武士有兩個方向的位移/衝刺技,且都需要消耗10點劍氣:必殺劍·曉天(54級,衝向目標,CD 5秒)用於欺近;必殺劍·夜天(56級,向後跳10米,CD 10秒)是武士唯一能主動拉開距離、閃避機制的技能。劍氣不足時兩者都無法發動。
- 心眼(6級)是唯一的個人減傷技,但只減輕「下一次攻擊」10%傷害且僅持續4秒,CD 15秒。對頭目的大招傷害幫助有限,不要高估其防禦力,且必須是「這4秒內第一次挨打」才吃到減傷。
- 意氣衝天(68級)、必殺劍·紅蓮(70級)是主要爆發窗口技能,死亡若發生在這些技能剛用完前後,代表玩家正處於爆發輸出節奏中。
- 必殺劍系列(震天/九天/曉天/夜天/紅蓮)都需要消耗劍氣才能發動,劍氣不足時死亡當下這些技能其實是不可用的。
