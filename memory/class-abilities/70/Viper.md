# 蝰蛇劍士 Viper (Viper)

**用途**:UWU(絕・究極武器破壞作戰)固定同步在 70 級,寫死亡片段的死因分析時用來查這個職業在 70 級同步下實際持有的技能與用途。本表只列 70 級當下實際會用到的最新版本技能,不重複列出被取代的舊版本。

**來源**:基於 https://ff14.huijiwiki.com/wiki/蝰蛇剑士 現行版本(7.51)資料整理(2026-07-26 讀取)。

**重要更正**:蝰蛇劍士的職業任務實際要求角色達到 **80 級**才能解鎖(灰機wiki原文:「任意80級及以上的戰鬥精英/魔法導師職業,完成80級蝰蛇劍士特職任務」),不是坊間常誤傳、也不是本repo先前假設的100級。但這不影響「蝰蛇劍士能否出現在70同步的UWU死亡紀錄裡」的結論方向——道理與鐮鐮客/賢者的70級開荒完全相同:蝰蛇劍士的wiki技能列表上標示的「N級」只是這個職業自己內部的技能解鎖曲線,不是真正需要的角色等級。因為蝰蛇劍士要求解鎖時角色已經≥80,所有標示「80級以下」的技能其實是解鎖當下就同時到手。玩家只要先把這個職業練起來,再帶進同步70級的內容,實際可用的就是這裡列出的「內部標示等級≤70」技能——所以蝰蛇劍士確實會出現在UWU死亡紀錄裡,只是玩家必須先在其他職業練到80級才能取得這個職業。

## 70 級當下的重點提醒

- 蝰蛇劍士在70同步下**沒有任何個人主動減傷或護盾技能**:蛇行只是位移,敏捷只是移速+控場免疫,兩者都不減傷,浴血是「自傷轉自療」不是減傷。死因分析時不要誤以為這個職業有防禦工具可以開。
- 目前(7.51版本)近戰DPS職能技能已改版為固定3個:浴血/敏捷/猛擊,舊版的牽制、真北、掃腿、親疏自行、內丹等已不在職能技能列表中——這點連同職業本身的技能都要以本表為準,不要套用其他資料來源記憶的舊版職能技能。
- 蛇行(20米瞬間移動)是蝰蛇劍士唯一的位移/拉開距離手段,CD 30秒,且沒有反向版本(不像鐮鐮客有進/出兩個方向可用)。
- 浴血是唯一自我治療手段,CD 45秒,且是「自傷轉自療」(必須先攻擊才有回復),不是被動或主動減傷。
- 强碎灵蛇/强碎灵蝰会持續累積「飛蛇之魂」層數,但消耗這個資源的終極技能(祖靈降臨 Reawaken)要到90級才解鎖——70同步下這份資源只能持續累積、永遠用不到,分析死因時不用考慮這個資源的釋放時機。
- 猛袭盘蛇/疾速盘蛇/猛袭盘蝰/疾速盘蝰雖然是戰技(佔GCD),但各自另有一段獨立的3秒複唱,實務上不太會卡到,幾乎不影響輸出節奏。
- 這個職業在70同步下的技能表看起來條目不算少(21個GCD+6個OGCD),但這是因為蝰蛇劍士的連段被拆成非常多細小分支(每一擊都有兩個交替路徑),不代表玩家實際手法複雜——蝰蛇劍士真正的角色等級門檻是**80級**(遠高於UWU的70同步),所以玩家在70同步下拿到的都是這個職業最初階、尚未成形的版本,完全沒有解鎖雙劍合一形態、祖靈降臨終結技、或任何個人減傷/控場手段,這是預期中的現象,不是資料缺漏。
