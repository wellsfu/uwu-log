# 賢者 Sage (Sage)

**用途**:UWU(絕・究極武器破壞作戰)固定同步在 70 級,寫死亡片段的死因分析時用來查這個職業在 70 級同步下實際持有的技能與用途。本表只列 70 級當下實際會用到的最新版本技能,不重複列出被取代的舊版本。

**來源**:基於 https://ff14.huijiwiki.com/wiki/贤者 現行版本(7.51)資料整理(2026-07-26 讀取)。

## 70 級當下的重點提醒

- 賢者擁有完整的單體/範圍治療、輸出咒語循環,以及輸血、堅角清汁、寄生清汁等護盾/減傷手段,技能量與其他治療職相當。
- 心關是賢者的核心被動機制:連結對象承受的部分傷害會轉移到賢者自己身上,死因分析時若賢者死於「莫名其妙偏高」的傷害,可能是心關連結對象剛好吃到大招,傷害轉移疊加所致。
- 輸血(Haima)是唯一明確驗證的高強度單體護盾技能,CD長達120秒;死亡分析時如果死亡發生在輸血用掉不久的空窗期,代表這個保命工具已經打掉。
- 堅角清汁、寄生清汁是賢者的地面型減傷/護盾範圍技能,若死亡當下玩家不在賢者的範圍技作用區內,代表沒有吃到這層保護。
- 神翼(Icarus)是賢者唯一的主動位移技能,只能瞬移到隊友身邊,不能自由方向移動,躲避需要「自由移動」的機制時要注意這個限制。
- 職能技能分頁在 wiki 上因頁面模板問題無法切換顯示,與白魔法師/學者/占星術士三個治療職頁面情況相同;僅淨化(康復/Esuna)經學者頁面交叉驗證確認適用賢者,已列入上表,其餘職能技能(如救援/位移類、安息/控場類)未能取得,死因分析時仍應假設賢者持有這些治療職共用技能。
