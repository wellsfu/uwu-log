# 武僧 Monk (Monk)

**用途**:UWU(絕・究極武器破壞作戰)固定同步在 70 級,寫死亡片段的死因分析時用來查這個職業在 70 級同步下實際有哪些技能、每個技能的用途,判斷玩家死亡當下手上有沒有對應的減傷/位移/爆發技能可用。

**來源**:https://ff14.huijiwiki.com/wiki/武僧 ,現行版本(7.51)資料,2026-07-26 讀取整理。技能解鎖等級會隨版本改動(relevel)而變化,以此表現行版本等級為準,不要用舊版本記憶判斷。

## 70 級當下的重點提醒

- 武僧沒有無敵技能。硬直/擊退類保護只有職能技能「親疏自行」(免疫擊退牽引)。
- 唯一的主動位移是「輕身步法」(35級,3次疊加,30秒CD),沒有第二個位移/衝刺技能;死亡若涉及來不及跑機制,要看輕身步法是否在CD中。
- 唯一的主動減傷技是「金剛極意」(64級,20%減傷+受擊後回血,CD 120秒),CD很長,死亡當下若非開過不久,通常是沒開或在CD中。
- 職能技能「牽制」是對頭目輸出降傷的手段,若死亡是被頭目普攻/AOE打死,可檢查牽制是否有上。
- 「掃腿」對雜兵/小怪可用於中斷,對絕本頭目通常無效或有機制限制,實際效果需依戰鬥設計判斷。
