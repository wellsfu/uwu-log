# 忍者 Ninja (Ninja)

**用途**:UWU(絕・究極武器破壞作戰)固定同步在 70 級,寫死亡片段的死因分析時用來查這個職業在 70 級同步下實際有哪些技能、每個技能的用途,判斷玩家死亡當下手上有沒有對應的減傷/位移/爆發技能可用。

**來源**:https://ff14.huijiwiki.com/wiki/忍者 ,現行版本(7.51)資料,2026-07-26 讀取整理。技能解鎖等級會隨版本改動(relevel)而變化,以此表現行版本等級為準,不要用舊版本記憶判斷。

## 70 級當下的重點提醒

- 忍者是這五個近戰DPS裡少數有「個人主動減傷技」的:殘影(2級,抵銷20%最大體力傷害,持續20秒,CD 120秒)。CD很長,死亡當下若非剛開過,通常在CD中。
- 唯一的主動位移是縮地(40級,20米,CD 60秒),沒有第二個位移技能;死亡若涉及來不及跑機制,要看縮地是否在CD中。
- 攻其不備(18級)、介毒之術(66級)、天地人(70級)是忍者的主要爆發窗口技能,死亡若發生在這些技能剛用完前後,代表玩家正處於爆發輸出節奏,操作上可能來不及應對機制。
- 冰遁之術(45級)發動後會讓施法者自動攻擊停止15秒,這是技能自帶副作用,不是被機制定身,分析死因時不要混淆。
- 忍術系統(天/地/人之印 + 忍術鍵)需要正確結印順序才能發動對應忍術,結印中無法穿插其他技能(天地人發動中除外),死亡若發生在結印過程中,玩家當下手上等於沒有其他技能可用。
