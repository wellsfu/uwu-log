# 龍騎士 Dragoon (Dragoon)

**用途**:UWU(絕・究極武器破壞作戰)固定同步在 70 級,寫死亡片段的死因分析時用來查這個職業在 70 級同步下實際有哪些技能、每個技能的用途,判斷玩家死亡當下手上有沒有對應的減傷/位移/爆發技能可用。

**來源**:https://ff14.huijiwiki.com/wiki/龙骑士 ,現行版本(7.51)資料,2026-07-26 讀取整理。技能解鎖等級會隨版本改動(relevel)而變化,以此表現行版本等級為準,不要用舊版本記憶判斷。

## 70 級當下的重點提醒

- 龍騎士的位移技能特別多,但方向都不一樣:跳躍(30級)、龍翼滑翔(45級)、龍炎衝(50級)都是「衝向目標」;只有回避跳躍(35級)是「向後跳15米」,是龍騎士唯一能主動拉開距離/閃避機制的技能,CD 30秒。
- 龍騎士沒有主動減傷技能,也沒有無敵技能;職能技能(牽制/親疏自行/內丹/浴血)之外沒有額外的自我保護手段。
- 貫穿尖(15級)是距離20米的遠程攻擊,搆不到目標時可以先用這個而不必勉強貼近。
- 戰鬥連禱(52級)、武神槍+死者之岸(60級/70級)是輸出爆發窗口,若死亡發生在這些技能剛用完前後,代表玩家當下正處於輸出爆發節奏中,不太可能同時有多餘技能應對機制。
